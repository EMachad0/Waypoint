# Decision records

One file per decision, numbered in sequence: `0001-slug.md`, `0002-slug.md`, and so on.

A decision earns a record only when it is hard to reverse, surprising without context, and the
result of a real trade-off. `/grill-with-docs` offers one when a decision resolves, and `/waypoint`
offers one at landing. The bar above is what decides, so both offers are rare. Format rules live in
the `domain-modeling` skill, in `ADR-FORMAT.md`.

A record states the decision as it stands, written for a reader who never saw the effort behind it.
One record can cover several tickets, and each ticket it came from keeps the answer it closed with.
