# Decision records

One file per decision, numbered in sequence: `0001-slug.md`, `0002-slug.md`, and so on. None
recorded yet, so the first one is `0001-`.

`/grill-with-docs` writes these, and only when a decision is hard to reverse, surprising without
context, and the result of a real trade-off. Format rules live in the `domain-modeling` skill, in
`ADR-FORMAT.md`.
