# Issues

The record of this repo's efforts. One directory per effort, holding `map.md`, `tickets/`, and
`resources/`. Nothing here is deleted. An issue closes by its `Status:` line, so a landed effort
stays in the tree.

An open issue describes what is not true yet. A closed one is history, what was decided or built at
the time. Neither states current convention. That lives in the docs one level up, in
`docs/CONTEXT.md`, and in `docs/adr/`.

Conventions and Waypoint operations: `docs/agents/issue-tracker.md`. Status strings:
`docs/agents/triage-labels.md`.
